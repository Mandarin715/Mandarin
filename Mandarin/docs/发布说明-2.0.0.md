# Mandarin v2.0.0 — Live2D 桌面陪伴

**2.0 的重点是让桌面角色动起来。** 从静态立绘走向 Live2D，角色会呼吸、眨眼、轻轻摆动，在聊天中改变表情，并随日语配音开合嘴巴。目前主要维护亚托莉（ATRI），PNG 立绘模式继续保留。

## Live2D：角色表现成为连续演出

- **自然待机**：呼吸、自动眨眼、待机摆动与模型物理共同驱动角色，聊天空闲时也保持动态。
- **情绪过渡**：AI 回复中的心情映射到模型参数，表情平滑切换；没有映射的心情回到中立表情。
- **语音口型**：按实际语音响度驱动嘴巴开合，句间停顿收口；日语台词使用中文回复的对应翻译。口型采用响度驱动，并非音素级口型。
- **内心独白**：独立的半透明气泡跟随角色移动，优先放在头顶，靠近屏幕边缘时调整位置，减少遮挡脸部。
- **清晰显示**：保持人物比例，适配高 DPI，支持独立的渲染画质缩放；重启后恢复设置中保存的人物大小。

## 亚托莉换装与临时表情

- 右键角色打开可拖动的装扮面板，提供衣服、鞋子、道具与视觉开关、组合和复位。
- 选完一个选项后面板保持打开，可以连续换装；再次右键角色或在面板外右键关闭，修复关闭后立即重开的情况。
- 在聊天中明确说「换上睡衣」「换上凉鞋」等，程序核对用户目标与 AI 动作后执行。自动换装只开放服装和鞋子。
- 震惊时可临时切到白眼，分句停顿不会提前结束，整条语音完成后恢复之前的手动状态；纯文字回复约 2.5 秒后恢复。
- 手动装扮当前不跨重启保存，重载模型恢复默认；其他模型需要各自的映射和装扮表。

## 如何启用

下载 `Mandarin-v2.0.0-portable.zip`，解压后通过 **`启动.bat`** 启动。包内新增 **`Live2D使用说明.md`** 和 **`live2d-presets/`**，提供模型目录、预设安装、配置开关及操作步骤。

默认仍为 PNG。准备好对应模型，按使用说明把配置设为 `renderMode=live2d`；亚托莉使用 `live2dModel=atri`。模型缺失或加载失败时回退 PNG。

便携包只提供我们自己编写的参数映射与预设，**不包含 Live2D 模型本体**。语音合成继续使用独立的 vits-simple-api 服务，亚托莉选择 `VITS - 4 - ATRI`。

## 可靠性修复

本次同时纳入聊天记录残缺行恢复、后台语音识别/截屏线程生命周期、VITS speaker ID、旧语音回调和表情定时器隔离，以及 Cubism 运行时引用和 GL 资源销毁修复。1.14.4 的原子存储、记忆唯一身份、提醒交付重试、OAuth 请求隔离与日语翻译约束继续保留。

Live2D 参数与窗口交互由实际模型回归验证；AI 自动换装和配音内容仍取决于所接入模型的输出，真实 LLM 与语音服务的完整链路尚未实机验证。没有自动启动桌宠。
