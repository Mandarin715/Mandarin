# 视觉感知 + 主动对话方案（v2.0，讨论修订版）

> 2026-07-06 修订，替代原方案

## 目标

桌宠能感知用户当前在干什么，在合适的时机主动发起对话。

## 核心设计原则

1. **规则触发，LLM 生成** — 触发判断用简单规则（免费），说话内容用 LLM
2. **窗口标题为主，截图为辅** — 减少 API 费用
3. **不打扰** — 离开时不说话，冷却期内不重复

## 砍掉的内容

- 摄像头（多数 PC 无摄像头/常年盖住）
- LLM 决策循环（每 30 秒调 LLM 判断，成本高）

## 触发源与优先级

### 第一层：窗口标题变化（最快、免费、主要）

每秒轮询 `GetForegroundWindow` + `GetWindowText`。

| 检测到 | 分类 | 主动说什么 |
|--------|------|-----------|
| 切到 IDE/编辑器 | VS Code, JetBrains | "又在写代码呀？这次做什么项目呢～" |
| 切到游戏 | Steam, 原神 | "哇，要打游戏了吗？带我一个！" |
| 切到视频/直播 | B站, YouTube | "在看什么呢？让我也瞧瞧～" |
| 切到社交媒体 | 微信, QQ, Discord | "刷到什么好玩的了吗？" |
| 切到文档/办公 | Word, Excel, WPS | "在忙工作吗？需要帮忙的话叫我哦" |
| 切到终端 | CMD, PowerShell | "又在调什么东西？别把电脑搞坏了……" |

防重复：驻留确认 30 秒 + 冷却期 10 分钟。

### 第二层：用户回来（免费）

`GetLastInputInfo()` 轮询系统键鼠时间。

| 状态 | 条件 |
|------|------|
| 离开 | 最后输入 > 30 分钟 |
| 回来 | 离开后检测到 3 秒内有输入 → "你回来啦！我都等了好久～" |

### 第三层：空闲时间（免费）

| 条件 | 行为 |
|------|------|
| 空闲 10 分钟 | 轻度问候 |
| 空闲 30 分钟 | 不打扰（交给回来检测） |
| 凌晨 | "这么晚了还不睡？" |
| 早上首次交互 | "早安！今天也要加油哦～" |

### 第四层：截图 + Vision（有费用，低频）

每 N 分钟截一次屏，仅窗口检测无法确定类型时送 Vision。

## 决策上下文

触发时构建 prompt 发给 LLM：

```
[当前时间] 2026-07-06 23:15
[上次交互] 18 分钟前
[当前窗口] steam.exe — "Counter-Strike 2"
[用户记忆] 名字：陌鸳, 喜好：编程
[用户位置] 河南安阳
```

## 聊天栏清理

主动对话触发时，如上次残留内容，先清空再发。通过标记区分主动消息和用户输入。

## 复用

- AI 调用 → `configureAiProvider()`
- 回复处理 → `replyReceived` 信号链（心情+显示+TTS+独白）
- 截图 → `captureScreenToJpeg()` + `analyzeScreenWithVision()`
- 定位 → `m_cachedLocation`（支持手动设置）
- 记忆 → `buildMemoryContext()`

## 不做的

- 天气/新闻 API（后加）
- 摄像头
- LLM 决策循环
