# Mandarin 2.0 — Live2D 桌面陪伴

Live2D 让角色的呼吸、眨眼、表情和嘴巴开合成为连续演出。Mandarin 保留 PNG 立绘，并允许已经准备好模型的用户切换到 Live2D。目前以亚托莉（atri）为主要维护角色。

## 能体验到什么

| 体验 | 表现 |
| --- | --- |
| 自然待机 | 呼吸、眨眼、待机摆动与模型物理共同驱动角色 |
| 对话表情 | AI 回复的心情映射为模型表情，平滑切换 |
| 语音口型 | 按语音响度开合嘴巴，句间停顿收口；属于响度驱动，不是音素级口型 |
| 内心独白 | 半透明气泡跟随角色，优先位于头顶，靠近屏幕边缘时调整位置 |
| 手动换装 | 亚托莉可切换衣服、鞋子、道具与视觉开关，支持组合及复位 |
| 聊天换装 | 明确说「换上睡衣」「换上凉鞋」等，程序校验目标与 AI 动作后执行 |
| 震惊演出 | 亚托莉震惊时临时白眼，整条语音完成后恢复；纯文字回复约 2.5 秒后恢复 |
| 大小与画质 | 启动恢复人物大小，高 DPI 下保持人物比例；画质缩放单独设置 |

装扮面板中选择一个选项后可以继续选择。按住标题栏左键拖动；再次右键角色或在面板外右键关闭。面板里的「显示／隐藏对话框」按钮切换聊天窗口。

当前手动装扮不跨重启保存，重载模型恢复默认。临时白眼结束时恢复此前的手动状态，不改变衣服和鞋子。聊天自动换装只开放衣服、鞋子，未明确要求换装时不会执行；其他模型需要自己的装扮表才有对应功能。

## 首次启用：以亚托莉为例

1. 准备你可使用的 atri Live2D 模型，在设置中导入/选择亚托莉角色包。便携版不包含模型本体。
2. 模型放到 `Documents/Mandarin/Live2D/atri/`，目录内应有 `.model3.json` 入口及其引用的 moc、纹理等文件。也支持模型位于角色目录 `Documents/Mandarin/Character/Assets/亚托莉/Live2D/atri/`。
3. 将便携版 `live2d-presets/atri/` 内的 `parameter-map.json` 和整个 `presets/` 目录复制到 `Documents/Mandarin/Character/Assets/亚托莉/Live2D/atri/`。这些是表情、待机和装扮所需的映射；应用不会自动读取便携版中的备份目录。
4. 退出桌宠，在 `Documents/Mandarin/config.ini` 现有的 `[character]` 段中合并下面配置，不删除其他设置，不创建重复的同名段：

   ```ini
   [character]
   CharSelect=亚托莉
   renderMode=live2d
   live2dModel=atri
   live2dFps=60
   live2dScale=1.0
   ```

5. 通过便携版的 `启动.bat` 启动。人物右键打开装扮面板；没有装扮表的模型仍使用原右键聊天行为。

`Documents` 指系统的「文档」目录，部分电脑会重定向到 OneDrive。先选择角色再修改配置，可以沿用角色包已有的语音和性格。

`live2dScale` 控制渲染画质，不是人物在桌面上的大小。人物大小仍在设置页调整。默认 60 FPS、1.0 倍渲染；提高帧率或画质会增加渲染开销，实际帧率取决于电脑与模型。

切回 PNG：退出后将 `renderMode` 改为 `png` 再启动。模型缺失或加载失败也会回退到 PNG，已有角色和聊天数据继续使用。

## 语音与预设

日语配音继续由独立的 vits-simple-api 服务提供；亚托莉选择 `VITS - 4 - ATRI`。程序会加强第三段日语对第二段中文的忠实翻译要求，第四段内心独白不会送入配音。生成约束不等同于语义校验，实际效果取决于所接入的模型。

便携版附带的 `live2d-presets/` 只含我们自己的参数映射和预设，不含作者模型。miku 与樱花miku 保留为备用，各自需要对应模型和预设，不能直接套用 atri 的参数表。
