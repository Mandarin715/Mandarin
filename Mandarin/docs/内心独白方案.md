# 内心独白方案（待实施）

> 2026-07-04 设计，暂不实施

## 目标

AI 回复中除了显示出来和读出来的内容外，增加一段"内心独白"——角色没说出口的想法，以半透明气泡飘在头顶，短暂停留后消失。

让角色更有灵魂感：嘴上说一套，心里想一套。类似漫画里的"内心OS"气泡。

## 效果示例

```
用户: 这么晚了还在写代码
AI 回复: 担心|是啊，今天任务有点多|そうですね、ちょっと大変です|（其实已经写完了，只是不想睡觉）
                                        ↑            ↑              ↑                    ↑
                                      心情          中文            日语               内心独白 ✨
                                                                                  
桌面表现:                                                                   
  聊天框: "是啊，今天任务有点多"（白色气泡）                                        
  立绘: 担心表情                                                                   
  语音: "そうですね、ちょっと大変です"                                              
  头顶: "其实已经写完了，只是不想睡觉"（半透明灰色气泡，3 秒后自动消失）✨              
```

## 架构

```
当前格式:  心情|中文|日语
新格式:   心情|中文|日语|内心独白（可选）

解析:
  finalReply.section('|', 0, 0) → mood
  finalReply.section('|', 1, 1) → chinese
  finalReply.section('|', 2, 2) → japanese
  finalReply.section('|', 3, 3) → innerThought ← 新增

如果 innerThought 非空:
  → 在 Tachie 窗口上方显示一个半透明 QLabel
  → 淡入 → 停留 3 秒 → 淡出消失
  → 用 QPropertyAnimation 做 opacity 动画
```

## 系统提示词修改

在 `doSubmitCurrentInput()` 中的系统提示词加一段：

```
4. 在日语后面可以添加内心独白（可选），用()括起来：
   格式：心情|中文|日语|（内心独白）
   内心独白是角色没说出口的真实想法，可以是吐槽、真实感受、小心思。
   长度不超过 20 字。
   没有想说的可以不加。
   
示例：
   开心|今天天气真好！|いい天気！|（这家伙终于出门了）
   不耐烦|好的知道了|はいはい|（好烦，能不能换个话题）
```

## 界面实现

在 `Tachie` 窗口之上叠加一个半透明气泡：

```cpp
// Tachie.cpp 新增方法
void Tachie::ShowInnerThought(const QString &text) {
    if (text.isEmpty()) return;
    
    auto *bubble = new QLabel(text, this);
    bubble->setStyleSheet(
        "color: #666; background: rgba(240,240,240,180); "
        "border-radius: 10px; padding: 8px 14px; font-size: 13px;");
    bubble->adjustSize();
    // 定位在立绘头顶
    bubble->move((width() - bubble->width()) / 2, -bubble->height() - 10);
    bubble->show();
    
    // 淡入 → 停留 3s → 淡出 → 删除
    auto *effect = new QGraphicsOpacityEffect(bubble);
    bubble->setGraphicsEffect(effect);
    auto *anim = new QPropertyAnimation(effect, "opacity", bubble);
    anim->setDuration(500);
    anim->setStartValue(0.0);
    anim->setEndValue(1.0);
    anim->start();
    
    QTimer::singleShot(3500, bubble, [bubble]() {
        auto *fadeOut = new QPropertyAnimation(
            qobject_cast<QGraphicsOpacityEffect*>(bubble->graphicsEffect()), 
            "opacity", bubble);
        fadeOut->setDuration(500);
        fadeOut->setStartValue(1.0);
        fadeOut->setEndValue(0.0);
        connect(fadeOut, &QPropertyAnimation::finished, bubble, &QObject::deleteLater);
        fadeOut->start();
    });
}
```
