# 聊天记录持久化方案（精简实施版）

> 2026-07-04 设计 · 2026-08-21 优化 · 2026-08-22 Pro 修订（压缩运行时化/停止双写/日期合成）
> **2026-08-31 定稿精简版**：**搁置「会话管理」（新建/切换/列表）**——桌宠偏养成系，每个角色保持一条连续聊天记录，切角色即天然"换会话"。本轮只做：**持久化不丢 + 旧版迁移 + 运行时压缩**。

## 目标

1. **持久化** — 每条消息**提交即落盘**（JSONL 追加），关掉重开/崩溃重启不丢最后一条
2. **干净存储** — 磁盘只存**原始消息**，永不删改；压缩是运行时行为，不落盘
3. **无感升级** — 旧 `context.json` 一次性迁移到 JSONL（`.legacy` 留档），老用户无感
4. **保留记忆** — `memory.json`（用户个人信息，如名字"陌鸳"）**不隔离、不动**
5. **不动角色提示词** — `Character/Assets/<角色>/config.json` 的 prompt 不修改

## 数据布局（精简后）

```
Documents/Mandarin/Character/UserConfig/<角色>/
├── chat.jsonl            # ✨ 新：原始消息日志（JSONL，每行一条，追加写）
├── context.json          # 旧格式；首次运行时迁移后改名 context.json.legacy，不再读写
├── memory.json           # 不变（跨会话共享的用户记忆）
└── config.json           # 不变
```

### 消息 schema

```json
{"id":"m_1a2b3c","role":"user","content":"今天天气好热啊","time":"2026-08-31T19:00:00+08:00"}
{"id":"m_1a2b3d","role":"assistant","content":"开心|是啊|そうだね|（内心）","time":"2026-08-31T19:00:03+08:00","meta":{"mood":"开心"}}
{"id":"m_1a2b3e","role":"assistant","content":"（历史摘要）","time":"...","meta":{"summary":true}}
```

- `role`：`user` / `assistant`；`content`：assistant 存原始 `心情|中文|日语|内心独白` 四段格式，展示时解析
- `time`：带时区 ISO8601；用于列表排序与**日期标记合成**
- `meta.summary`：**仅迁移产物**（旧 context.json 的 `角色：[对话摘要] xxx` 迁移时打标）
- `meta.mood`：冗余存心情，便于会话预览（当前不展示也可）

## 核心设计

### 持久化：消息即写即存

- 每条消息（用户输入、AI 回复）在加入内存上下文的同时 **append 一行到 chat.jsonl**（小写入，毫秒级）
- 不再需要 `scheduleContextSave()` 的 2 秒防抖——**该函数移除**
- 崩溃最多丢半行：读取时坏行跳过 + `qWarning`，不损坏整个文件
- `QApplication::aboutToQuit` 钩子兜底 flush（当前追加即落盘，此钩子为防御性）

### 加载与日期合成

- 启动加载：读 chat.jsonl → 重建内存上下文行 `m_contextHistory`
- 重建时**按 time 的日期分组，日期变化时临时插入 `[M月d日]` 标记**（不再存数据行）
- 运行中消息日期变化 → 仅在内存上下文插入日期标记行（不写入 chat.jsonl）

### 压缩：运行时，不落盘

- 沿用现状：内存上下文超 60 行 → 异步 AI 压缩最旧 20 行为 1 条摘要（`m_contextGeneration` 代际校验 + 快照比对）
- **只改内存视图，不写回 chat.jsonl**（磁盘永远是原始消息）
- 移除压缩完成后的 `scheduleContextSave()` 调用

### 迁移（一次性）

```
首次运行（每角色目录）：
  1. 若 chat.jsonl 存在 → 直接加载
  2. 若 chat.jsonl 不存在且 context.json 存在：
     a. 读 context.json 的 history 数组
     b. 逐行解析：
        "用户：xxx"             → {role:user, content:xxx}
        "角色：xxx"             → {role:assistant, content:xxx}
        "角色：[对话摘要] xxx"  → {role:assistant, content:xxx, meta:{summary:true}}
        "[M月d日]" 日期行       → 更新当前日期（用于合成 time），不落为消息
     c. time：日期行更新日期基准；消息 time = 当前日期 + 递增秒数（保留顺序）
     d. 写 chat.jsonl；context.json 改名 context.json.legacy
```

## 风险

| 风险 | 对策 |
|------|------|
| 旧版本升级 | 一次性迁移 + `.legacy` 留档安全网 |
| 文件损坏 | JSONL 逐行容错（坏行跳过 + 日志） |
| 崩溃丢最后一条 | 提交即落盘（无防抖窗口） |
| 迁移时间戳不准 | 日期行驱动日期 + 递增秒保序（可接受） |
| 压缩与持久化耦合 | 压缩只改内存，不写盘 |
